# Internationalization (docs)

Ariadne documentation is **bilingual for user-facing pages**, with **English as the normative language** for design contracts.

## Layout

| Path | Language | Role |
| --- | --- | --- |
| `README.md` | English | Product landing (GitHub default) |
| `README.zh-CN.md` | 简体中文 | Product landing |
| `docs/USAGE_CLI.md` | English | Host / CLI / web usage |
| `docs/zh/USAGE_CLI.md` | 简体中文 | Host / CLI / web usage |
| `docs/README.md` | English | Docs index + design map |
| `docs/zh/README.md` | 简体中文 | Docs index for Chinese readers |
| `docs/*.md`, `docs/design/` | English | Normative design (architecture, memory, tools, …) |

## Rules

1. **User-facing** (install, usage, screenshots, quick start): keep **EN + ZH** in sync when behavior changes.  
2. **Design / contracts** (public API shapes, error codes, memory layers): edit **English** first; Chinese pages may summarize and link.  
3. Cross-link language variants at the top of each paired page (`English` · `简体中文`).  
4. Do not leave API keys or real secrets in examples; use placeholders.

## Adding a new language

1. Prefer `README.<locale>.md` and `docs/<locale>/…` (BCP 47 style, e.g. `zh-CN`).  
2. Link from both README files and both docs indexes.  
3. Update this file’s table.
